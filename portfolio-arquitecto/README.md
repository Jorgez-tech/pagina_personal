# Portfolio para Arquitecto

Sitio estático (HTML/CSS/JS) para estudio de arquitectura.

## Vista previa local

```powershell path=null start=null
python -m http.server 8000 -d .
```

```powershell path=null start=null
npx serve . -l 8000
```

## Despliegue recomendado (Chile)

- GitHub Pages, Netlify o Vercel.
- Hosting en Chile: Hostinger Chile, WebHosting Chile, ChileHosting.
- Dominio .cl a través de NIC Chile.

## Personalización rápida

- Edita `index.html` (servicios, proyectos, contacto).
- Ajusta paleta y tipografías en `css/style.css`.
- Conecta el formulario en `js/main.js`.
