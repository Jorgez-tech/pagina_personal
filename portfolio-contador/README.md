# Portfolio para Contador Auditor

Sitio estático (HTML/CSS/JS) para servicios contables y tributarios.

## Vista previa local

```powershell path=null start=null
python -m http.server 8000 -d .
```

```powershell path=null start=null
npx serve . -l 8000
```

## Despliegue recomendado (Chile)

- GitHub Pages, Netlify o Vercel.
- Hosting en Chile: Hostinger Chile, WebHosting Chile, ChileHosting.
- Dominio .cl vía NIC Chile.

## Personalización rápida

- Edita `index.html` (servicios, planes, contacto).
- Ajusta colores sobrios en `css/style.css`.
- Conecta el formulario en `js/main.js`.
