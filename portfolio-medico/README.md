# Portfolio para Médico

Sitio estático (HTML/CSS/JS) para consulta médica o clínica.

## Vista previa local

```powershell path=null start=null
python -m http.server 8000 -d .
```

```powershell path=null start=null
npx serve . -l 8000
```

## Despliegue recomendado (Chile)

- GitHub Pages, Netlify o Vercel (HTTPS, CI/CD y excelente rendimiento).
- Hosting con servidores en Chile: Hostinger Chile, WebHosting Chile, ChileHosting.
- Dominio .cl vía NIC Chile.

## Personalización rápida

- Actualiza `index.html` (especialidades, seguro, horario, contacto).
- Ajusta colores en `css/style.css`.
- Conecta el formulario en `js/main.js` con Formspree/EmailJS o backend propio.
